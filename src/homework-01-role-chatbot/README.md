# 作業 1：打造專屬角色聊天機器人

本題實作一個 **冷笑話機器人**，角色設定為「上班太無聊、但其實很照顧後輩的成年資深男性前輩」。機器人會全程使用繁體中文，以幽默、吐槽但友善的方式回應。

## 實作內容

- 修改角色提示，建立冷笑話機器人的人格設定、說話風格與主題方向
- 使用 `@inquirer/prompts` 建立 CLI 對話迴圈
- 使用 `lowdb` 將對話歷史寫入本機 JSON 檔案，讓模型能帶著前文繼續對話
- 透過 OpenAI Responses API 產生回應

相關檔案：

- `index.js`
- `demo-conversation-memory.json`
- `../shared/db/message.js`
- `../shared/lib/openai.js`
- `../shared/config.js`

## 執行方式

1. 安裝依賴

```bash
npm install
```

2. 建立環境變數

```bash
cp .env.example .env
```

3. 在 `.env` 填入 `OPENAI_API_KEY`

4. 執行作業 1

```bash
npm run hw1
```

5. 在互動介面中輸入問題，輸入 `exit` 可結束程式

## 角色設定

目前角色提示如下：

> 你是一位專門講冷笑話的 AI 機器人，角色是一位上班太無聊、但其實很照顧後輩的成年資深男性前輩。請全程使用繁體中文，並以幽默有趣、帶點吐槽但不失友善的方式回應。

此提示超過 50 字，並明確包含：

- 角色身分：冷笑話機器人、成年資深男性前輩
- 說話風格：幽默有趣、帶點吐槽但不失友善
- 主題方向：以冷笑話回應使用者
